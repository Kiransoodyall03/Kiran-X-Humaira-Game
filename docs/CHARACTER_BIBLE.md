## How to fill an entry
Start from the **ghost** (the past event), not the goal. Each part leads to the next:

```
NAME / ROLE / ONE-LINE HOOK
GHOST (past event)        →  WOUND (the damage)
LIE (false belief)        →  FLAW (how the lie shows in behavior)
WANT (conscious goal)     vs NEED (the truth that heals)
FEAR / VALUES / CONTRADICTION
VOICE: 3 sample lines · words they never use
SILHOUETTE KEY: 1 shape + 1 prop + 1 color
MECHANICAL EXPRESSION: how gameplay shows the flaw or arc
ARC BEATS (5): opening state → … → final state
```

Tell character through play and silhouette more than words. FromSoftware-style: few lines, each one loaded.
