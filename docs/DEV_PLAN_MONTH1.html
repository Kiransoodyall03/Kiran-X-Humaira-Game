Parallel-work rules

The “no interference” contract. Full detail lives in docs/WORKFLOW.md.

Tools & versions

  • Godot 4.7.2 on both machines, exactly. Upgrade together, only after 4.8.1.
  • Blender exports .glb; don't import .blend directly. Sources live in source_art/ (ignored by Godot).
  • Git + LFS from the first commit. .blend/.glb are lockable.
  • Commit .import and .uid files; move a .uid with its script.
  • GitHub for code; Anchorpoint for the modeler. LFS fallback: Gitea or Azure DevOps if the 10 GiB/month bandwidth runs out.

Branching & rhythm

  • main always opens and runs.
  • P 1–3 day feature branches → PR → Claude review.
  • A commits straight to main when only touching A-owned paths.
  • Pull before opening the editor. Tag milestones m1-w1…m1-final.
  • Mon 20-min sync · Wed async check-in · Fri 30-min play-together + retro.
Never edit an imported .glb scene. No Editable Children, no inherited scenes. The programmer wraps the glb in their own scene; the modeler re-exports in place. It keeps working as long as node and bone names stay stable.
Scene conflict? Don't hand-merge. Take one side and redo the other change in the editor.

Asset contract

Agreed by end of week 1 in docs/ART_SPEC.md. Greybox is built to these numbers so final art drops straight in.

Scale & pivots

  • 1 Blender unit = 1 m; apply transforms
  • Characters face +Z
  • Characters pivot at feet; props bottom-center
  • Modular pieces on a 1 m grid

Metrics

  • Heroine 1.70 m · doors 2.4 m
  • Climbs 1.0 m / 2.2 m
  • Monsters S 2–3 m · L 5–8 m · XL 12 m+

Naming & sockets

  • SM_ SK_ A_char_action MAT_ T_
  • Sockets: weapon_R weapon_back cat_perch
  • Suffixes: -col -colonly -navmesh -loop

Rigs

  • Heroine → SkeletonProfileHumanoid
  • Mixamo = placeholders only
  • Monsters: 2–3 shared rig families (oni, beast, serpent)

Budgets

  • Heroine 30–60k tris
  • Large monster 60–120k
  • Modular piece 1–10k
  • 512–1024 px/m texel density

Animation handoff

  • AnimationLibrary .glb files
  • Root motion on the root bone
  • Animate only clips locked in an attack table
