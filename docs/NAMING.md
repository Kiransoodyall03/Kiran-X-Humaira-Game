# Naming sheet

Owner: both (decide in joint sessions) · Status: shortlist in week 1, finals in week 4

## Rules
1. Build names from real Japanese morphemes with a known meaning. Record the reading, kanji and gloss for each.
2. Never use the names of real enshrined kami, real shrines or real clans — especially not for villains.
3. Treat Shinto/Buddhist concepts (purification, sealing, kami) as worldview, not a superpower menu.
4. Folklore reference: yokai.com (Matthew Meyer) plus scholarly sources; cross-check.
5. **Banned (Bleach terms):** zanpakutō, shinigami, Soul Reaper, Hollow, Menos, bankai, shikai, Soul Society, Gotei, Seireitei, kidō, hollowfication. Invent our own words for the sword's released forms.
6. Every name gets checked by a native Japanese speaker before it's final.
7. In code and file names, use placeholders (`heroine`, `cat`, `guardian`, `monster`) until a name is final.
